# Velocity — Bikes & Cars

A responsive React + Vite showcase website for bikes and cars.

## Features
- Modern dark theme with lime accents
- Responsive layout for desktop, tablet and mobile
- Filter vehicles by bikes or cars
- Search by vehicle name, category or type
- Save/unsave favourites (client-side state)
- Vehicle cards with sample specifications
- About section and footer

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Build for production

```bash
npm run build
npm run preview
```

## Add to GitHub
1. Extract this ZIP.
2. Create a new repository on GitHub.
3. Upload the extracted project files (including `src`, `package.json`, and `index.html`).
4. Commit the files.

The vehicle names and specifications are sample demo content. Replace them with your own listings before publishing.
